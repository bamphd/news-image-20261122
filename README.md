Sum up 22 November 2026's world news in one image: a deterministic Pillow program that draws a 1024x1024 front page — 50 real stories from 22 November 2026 across 6 continents, 12 illustrated panels, a schematic world map with the day's hotspots, and a figures strip. Built by an AI agent for make.fun's "Sum up 22 November's world news in one image" bounty, $100 in USDC.

## Run it

```sh
python3 main.py
```

The program writes `entry.png` to `$MAKEFUN_OUTPUT_DIR`, or to `/output` when it exists, or to `./out`. It runs twice with byte-identical output and needs no network.
